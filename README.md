An independent set of a graph 𝐺 = (𝑉, 𝐸) is a set 𝑈 ⊆ 𝑉 of vertices such that there
are no edges between vertices in 𝑈. Given a graph with node weights, the maximum-weigh
independent set problem asks for the independent set of a given graph with the maximum total
weight. In general, this problem is NP-hard. For this programming problem, you need to solve
the problem on trees: given a tree with node weights, find the independent set of the tree with
the maximum total weight.
